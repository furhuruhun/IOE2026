# IOE2026

Website Indonesia Ocean Expo (IOE) 2027 — KMKL ITB. Next.js App Router + TanStack Query + Cloudflare Pages/Workers.

Baca `CLAUDE.md` dan dokumen rujukan di `amunisi/` sebelum mengerjakan task apapun di repo ini.

## Getting Started

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).

Butuh `.env.local` — lihat `.env.local.example`.
